# Record Selection

Choosing which records to search for different research questions.

## Selection Principles

### The Right Record for the Question

Not all records answer all questions:
- Birth records answer birth questions
- Marriage records answer marriage questions
- Census records provide snapshots in time

**Match the record to the question.**

### The Funnel Approach

Start broad, then narrow:
1. Identify all possible record types
2. Prioritize by likelihood of answering question
3. Start with most likely, work outward
4. Stop when question is answered

### Time and Place Awareness

Records vary by:
- When they were created (vital records started at different times)
- Where they were kept (state vs. county jurisdiction)
- What survived (fires, disasters, neglect)

## Record Selection by Question Type

### Finding Birth Information

| Priority | Record Type | What It Provides |
|----------|-------------|------------------|
| 1 | Birth certificate | Date, place, parents |
| 2 | Church baptism | Date, place, parents, godparents |
| 3 | Family Bible | Date, usually less detail |
| 4 | Census (age) | Approximate year |
| 5 | Death certificate | Birth info (secondary) |
| 6 | Tombstone | Birth date (may be wrong) |
| 7 | Obituary | Birth info (usually secondary) |

### Finding Death Information

| Priority | Record Type | What It Provides |
|----------|-------------|------------------|
| 1 | Death certificate | Date, place, cause, informant |
| 2 | Obituary | Date, biographical info |
| 3 | Cemetery/tombstone | Date, burial location |
| 4 | Probate | Date range from filing |
| 5 | Census (absence) | Narrows date range |
| 6 | Social Security Death Index | Date, last residence |

### Finding Marriage Information

| Priority | Record Type | What It Provides |
|----------|-------------|------------------|
| 1 | Marriage license/certificate | Date, place, names, witnesses |
| 2 | Church marriage record | Date, place, religious details |
| 3 | Newspaper announcement | Date, families, details |
| 4 | Census (married status) | Approximate date if recent |
| 5 | Bible record | Date, usually less detail |

### Finding Parentage

| Priority | Record Type | What It Provides |
|----------|-------------|------------------|
| 1 | Birth certificate | Parents' names directly |
| 2 | Baptism record | Parents' names, godparents |
| 3 | Census (child in household) | Parents' names in context |
| 4 | Parent's probate/will | Names children |
| 5 | Marriage record (of child) | Parents sometimes named |
| 6 | Death certificate | Parents (often secondary info) |
| 7 | DNA testing | Biological relationships |

### Finding Migration

| Priority | Record Type | What It Provides |
|----------|-------------|------------------|
| 1 | Census series | Location changes over decades |
| 2 | Land records | Arrival, departure from area |
| 3 | Church transfer records | Movement between congregations |
| 4 | Tax lists | Presence or absence |
| 5 | City directories | Annual location tracking |
| 6 | Newspaper | Departure/arrival notices |

## Record Types Overview

### Civil Vital Records

**Birth certificates**
- Created: Varies by state (1880s-1920s for most)
- Location: State vital records office, county courthouse
- Content: Date, place, parents, sometimes occupation

**Death certificates**
- Created: Similar to births by state
- Location: State vital records, funeral homes
- Content: Date, place, cause, informant, parents (secondary)

**Marriage records**
- Created: Earlier than birth/death typically
- Location: County courthouse, state archives
- Content: Date, place, names, witnesses, sometimes parents

### Census Records

**Federal census** (every 10 years, 1790-1950 available)
- Location: NARA, online databases
- Content: Varies by year; name, age, birthplace, occupation

**State census** (varies by state)
- Location: State archives, online databases
- Content: Similar to federal, different years

### Church Records

**Baptism/Christening**
- Location: Church archives, denominational headquarters
- Content: Date, child, parents, godparents

**Marriage**
- Location: Church archives
- Content: Date, couple, witnesses, sometimes parents

**Burial**
- Location: Church archives
- Content: Date, name, sometimes cause, age

### Probate Records

**Wills**
- Location: County probate court
- Content: Heirs, relationships, property

**Administrations**
- Location: County probate court
- Content: Estate without will, heirs named

**Guardianships**
- Location: County probate court
- Content: Minor children, parents' status

### Land Records

**Deeds**
- Location: County recorder
- Content: Buyer, seller, property, date

**Patents/Grants**
- Location: Land office records, BLM
- Content: Original recipient, location

**Tax lists**
- Location: County/state archives
- Content: Taxpayers, property values

### Military Records

**Service records**
- Location: NARA, state archives
- Content: Service dates, unit, rank

**Pension files**
- Location: NARA
- Content: Service proof, family info, residence

**Draft registrations**
- Location: NARA, online
- Content: Name, address, physical description, relatives

### Newspapers

**Obituaries**
- Content: Death info, biographical, survivors

**Announcements**
- Content: Births, marriages, engagements

**Legal notices**
- Content: Probate, land sales, divorces

## Search Strategy by Era

### Pre-1850

Limited records; focus on:
- Church records
- Land records
- Tax lists
- Probate
- Early census (limited info)

### 1850-1900

Expanding records:
- Federal census (more detailed from 1850)
- Civil War records (for eligible)
- Early vital records (varies)
- Growing newspaper coverage

### 1900-1950

Rich record environment:
- Vital records widely available
- Detailed census
- Immigration records
- Social Security begins (1936)
- Military records (WWI, WWII)

### Post-1950

Most comprehensive but privacy restrictions:
- Census sealed until 72 years
- Some vital records restricted
- Living persons considerations

## Locality Considerations

### Before Searching

1. **Identify jurisdiction** at time of event
   - County boundaries change
   - States created from territories
   - Cities annex surrounding areas

2. **Check record availability**
   - When did jurisdiction start keeping this record?
   - Where are records now held?
   - Have records survived?

3. **Find the repository**
   - County courthouse
   - State archives
   - Online databases
   - FamilySearch microfilm

See [locality-research.md](locality-research.md) for more detail.

## Building a Source List

### For Each Research Question

1. List all potentially relevant record types
2. For each, determine:
   - Does it exist for this time/place?
   - Where is it located?
   - Is it accessible?
3. Prioritize by:
   - Likelihood of answering question
   - Accessibility
   - Reliability
4. Search in priority order
5. Document each search (positive and negative)
