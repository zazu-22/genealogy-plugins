# DNA Evidence

Overview of using DNA evidence to support genealogical research.

## When This Skill Applies

- Understanding DNA test types and their uses
- Evaluating DNA matches for relationship clues
- Integrating DNA evidence with documentary research
- Applying GPS standards to DNA-supported conclusions

## Core Concepts

### DNA in Genealogy

DNA testing provides **biological relationship evidence** that can:
- Confirm documented relationships
- Suggest previously unknown connections
- Break through brick walls
- Identify biological parents (adoptees)

### Key Principle

> DNA evidence shows biological relationships—it cannot tell you names, dates, or stories. It must be combined with documentary research.

## DNA Test Types

| Test | What It Tests | Inheritance | Best For |
|------|---------------|-------------|----------|
| **atDNA** | Autosomal DNA | All ancestors, dilutes | Finding relatives within ~6 generations |
| **Y-DNA** | Y chromosome | Father to son only | Tracing direct paternal line |
| **mtDNA** | Mitochondrial | Mother to all children | Tracing direct maternal line |

### Choosing a Test

- **Most people**: Start with autosomal (atDNA)
- **Paternal line question**: Add Y-DNA (males only)
- **Maternal line question**: Add mtDNA

## Quick Match Assessment

### Relationship Estimates

| Shared cM | Possible Relationships |
|-----------|----------------------|
| 3400+ | Parent/child, full sibling |
| 1700-2300 | Grandparent, aunt/uncle, half-sibling |
| 680-1150 | 1st cousin, great-grandparent |
| 200-620 | 2nd cousin, 1C1R |
| 50-200 | 3rd-4th cousin |
| <50 | Distant or coincidental |

**Note**: Ranges overlap—multiple relationships are often possible for a given cM amount.

## Working with Matches

### Basic Process

1. **Identify shared DNA amount** (cM)
2. **Note possible relationships** (use calculators)
3. **Find common ancestors** (shared matches, trees)
4. **Verify with documents** (confirm the paper trail)
