# Analysis and Correlation

GPS Element 3: Skillfully analyzing and correlating all evidence.

## The Standard

Evidence must be:

- **Analyzed**: Each piece evaluated for quality and relevance
- **Correlated**: All pieces compared and connected
- **Interpreted**: Meaning extracted through careful reasoning

## The Analysis Process

### Step 1: Classify Each Source

For every source, determine:

| Question | Classification |
|----------|----------------|
| Is this the original or a copy? | Original / Derivative / Authored |
| Who provided the information? | Primary / Secondary / Indeterminate |
| Does this answer my question? | Direct / Indirect / Negative |

### Step 2: Assess Reliability

Consider for each piece of evidence:

- How close in time to the event?
- What was the informant's knowledge?
- What motivation might affect accuracy?
- Is this consistent with other evidence?

### Step 3: Compare Across Sources

Build a correlation table:

| Fact | Source 1 | Source 2 | Source 3 | Assessment |
|------|----------|----------|----------|------------|
| Birth year | 1850 | ca. 1850 | 1851 | Consensus: 1850 |
| Birthplace | Ohio | Zanesville | Muskingum Co. | Consistent: Zanesville, Ohio |
| Father | John | J. Smith | [blank] | Likely: John Smith |

### Step 4: Weigh the Evidence

Apply the reliability hierarchy:

**More reliable** (generally):

- Original over derivative
- Primary over secondary
- Contemporary over later
- Official over informal
- Disinterested over interested party

**But context matters**:

- A careful derivative may beat a damaged original
- A motivated informant may still be accurate
- Later record may have access to better information

## Correlation Techniques

### Timeline Analysis

Plot events chronologically to check for:

- Impossible sequences (child born before parents married)
- Implausible gaps (20-year gap between siblings)
- Missing events (no death record for known deceased)

```
1845 ─── Parents marry
1847 ─── Child 1 born
1849 ─── Child 2 born
1850 ─── Subject born
1852 ─── Child 4 born
     ↑
     No gap issue; sequence logical
```

### Geographic Analysis

Map locations to check for:

- Logical migration patterns
- Impossible distances (Ohio one month, California next)
- Consistent locality references

### Name Pattern Analysis

Track name variations to identify same person:

- Spelling variants
- Nickname usage
- Translation effects

### Numerical Analysis

Calculate and verify:

- Ages across records (should be consistent)
- Birth years from ages (allow for birthday timing)
- Dates between events (pregnancies, marriages)

## Weighing Conflicting Information

### When Sources Disagree

1. **Identify the conflict**: What exactly differs?
2. **Compare source quality**: Which is more reliable?
3. **Consider informants**: Who knew what?
4. **Examine context**: What might explain the difference?
5. **Make reasoned judgment**: Which is more likely correct?

### Common Causes of Conflicts

| Conflict Type | Likely Cause |
|---------------|--------------|
| Age varies by 1-2 years | Rounding, birthday timing |
| Birthplace differs | Different levels of specificity |
| Name spelling varies | Phonetic recording, literacy |
| Different father named | Stepfather, adoptive, error |
| Date off by one day | Recording delay, timezone |

### Resolution Framework

```
Conflict: Birth year stated as 1850 in one source, 1851 in another

Analysis:
- Source 1 (1850): Birth certificate, primary information
- Source 2 (1851): Census age calculation, secondary information

Resolution: Birth certificate is original record with primary
information. Census age is a calculation from reported age,
subject to rounding. Accept 1850 from birth certificate.

Note: Census "age 49" in June 1900 consistent with March 1850
birth (had not yet turned 50).
```

## Synthesis

### Moving from Evidence to Conclusion

1. **Summarize findings**: What does each source say?
2. **Identify patterns**: Where does evidence agree?
3. **Address conflicts**: How do you resolve disagreements?
4. **Draw conclusion**: What does the evidence support?
5. **Assess confidence**: How certain is your conclusion?

### Confidence Levels

| Level | Criteria |
|-------|----------|
| **Certain** | Direct, primary evidence with no conflict |
| **Very confident** | Multiple consistent sources, minor conflicts explained |
| **Probable** | Preponderance supports, some uncertainty remains |
| **Possible** | Evidence suggests but doesn't prove |
| **Uncertain** | Insufficient evidence for conclusion |

## Quality Checks

### Before Concluding, Verify:

- [ ] Every relevant source has been analyzed
- [ ] Each piece classified correctly
- [ ] All evidence considered (not just supporting)
- [ ] Conflicts explicitly addressed
- [ ] Reasoning is documented
- [ ] Conclusion follows from evidence
