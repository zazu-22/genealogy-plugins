# Resolution of Conflicts

GPS Element 4: Addressing and resolving contradictory evidence.

## The Standard

When evidence conflicts, you must:
- **Identify** all contradictions
- **Analyze** why they might exist
- **Resolve** by reasoned explanation
- **Document** your resolution

**Ignoring conflicts fails GPS Element 4.**

## Types of Conflicts

### Minor Discrepancies

Small differences that don't change fundamental conclusions.

| Type | Example | Typical Cause |
|------|---------|---------------|
| Spelling | Smith vs. Smyth | Phonetic recording |
| Age ±1-2 years | 45 vs. 47 | Rounding, birthday |
| Date ±1 day | 15th vs. 16th | Recording time |
| Name form | John vs. Johann | Translation |

**Resolution**: Note the variation, explain likely cause, proceed.

### Moderate Conflicts

Significant differences requiring explanation but resolvable.

| Type | Example | Investigation |
|------|---------|---------------|
| Age ±5 years | 40 vs. 46 | Check informants |
| Different birthplace | Ohio vs. Kentucky | Check migration |
| Different spouse name | Mary vs. Maria | Check if same person |
| Parent name differs | John vs. James | Check for step-parent |

**Resolution**: Analyze source quality, identify more reliable, explain.

### Major Contradictions

Fundamental conflicts that challenge identity or relationships.

| Type | Example | Impact |
|------|---------|--------|
| Wrong parents | Different father named | Identity question |
| Wrong spouse | Different marriage | Family structure |
| Impossible date | Born after mother died | Record error or wrong person |
| Different person | Two people with same name | Separate identities |

**Resolution**: May require extensive research; may prevent conclusion.

## Resolution Process

### Step 1: Identify the Conflict

State exactly what conflicts:
```
Conflict: Death certificate states father as "William Smith"
but birth certificate states father as "James Smith."
```

### Step 2: Examine Each Source

For each conflicting source:
- What type of source is it?
- Who provided the information?
- When was it recorded?
- What motivation might affect accuracy?

### Step 3: Determine Likely Cause

Common causes of conflicts:

**Informant issues**:
- Didn't know correct information
- Misremembered
- Gave approximation
- Had reason to misstate

**Recording issues**:
- Clerk error
- Illegible writing misread
- Typographical error
- Wrong person's information recorded

**Identity issues**:
- Two people with same name
- Name changed over time
- Different name used in different contexts

### Step 4: Weigh the Evidence

Apply hierarchy of reliability:

| More Reliable | Less Reliable |
|---------------|---------------|
| Contemporary record | Later record |
| Original document | Derivative copy |
| Primary information | Secondary information |
| Disinterested party | Interested party |
| Official record | Informal record |

### Step 5: Make Reasoned Decision

Explain why one piece of evidence is preferred:
```
Resolution: The birth certificate (1850) provides father's name
from information likely provided by the parents at the time of
birth. The death certificate (1925) was completed by the subject's
adult child who may have been uncertain of grandfather's name.
The contemporary, primary information on the birth certificate
is accepted as more reliable.
```

### Step 6: Document Everything

Record:
- The conflict
- Both (all) sources
- Your analysis
- Your resolution
- Any remaining uncertainty

## Common Conflict Scenarios

### Age Discrepancies

**Scenario**: Census records show different ages across years.

**Analysis approach**:
1. Calculate implied birth year from each record
2. Consider birthday timing (had they turned X by census date?)
3. Identify who likely provided information
4. Check for pattern (always older? always younger?)

**Typical resolution**:
```
Birth year ranges from 1848-1852 across five census records.
Analysis of informants and census dates suggests consistent
birth in 1850. Variations attributed to:
- 1860: Birthday hadn't occurred; age 9 = born 1850-51
- 1880: Possible age rounding
- 1900: Self-reported; likely accurate
Accept 1850 based on preponderance and consistency.
```

### Name Variations

**Scenario**: Person appears with different names in records.

**Analysis approach**:
1. Document all name forms found
2. Identify contexts for each form
3. Check for translation/Anglicization
4. Verify same person via other identifiers

**Typical resolution**:
```
Subject appears as "Johann Schmidt" in church records (German)
and "John Smith" in civil records (English). Same person
confirmed by matching spouse name, residence, and children.
Name variation reflects language context of record.
```

### Conflicting Parentage

**Scenario**: Different parents named in different records.

**Analysis approach**:
1. Check if one might be step-parent
2. Check if one might be adoptive
3. Assess informant knowledge for each record
4. Look for additional corroborating evidence

**Typical resolution** (if resolved):
```
Birth certificate names "William Jones" as father. Marriage
record names "Robert Brown" as father. Research reveals mother
remarried after biological father's death; Robert Brown was
stepfather who raised the subject. Biological father confirmed
as William Jones.
```

### Impossible Dates

**Scenario**: Record shows date that's impossible.

**Analysis approach**:
1. Check for transcription error
2. Check for wrong person
3. Check for recording convention difference
4. Consider calendar changes

**Typical resolution**:
```
Marriage record shows date of 30 February 1850. This date is
impossible. Original record examined shows "20 February" -
transcriber misread "20" as "30." Correct date: 20 February 1850.
```

## When Conflicts Can't Be Resolved

### Acknowledging Uncertainty

Sometimes conflicts cannot be resolved:
- Evidence is equally balanced
- Critical record doesn't exist
- Multiple interpretations equally valid

**In such cases**:
1. Document the conflict
2. Present all evidence
3. Explain why resolution isn't possible
4. State that conclusion cannot be reached
5. Identify what evidence might resolve it

### Example

```
The father's given name cannot be definitively determined.
Birth certificate names "William Smith"; death certificate
names "James Smith." Both informants had plausible knowledge.
No additional records naming the father have been located.

Until further evidence emerges, parentage cannot be proven.
Research suggestion: Locate father's probate records, earlier
census enumerating father, or DNA evidence.
```

## Documentation Format

### Conflict Resolution Template

```
CONFLICT IDENTIFIED:
[Specific statement of what conflicts]

SOURCE 1:
- Citation: [Full citation]
- Information: [What it says]
- Type: [Original/Derivative; Primary/Secondary]
- Assessment: [Reliability factors]

SOURCE 2:
- Citation: [Full citation]
- Information: [What it says]
- Type: [Original/Derivative; Primary/Secondary]
- Assessment: [Reliability factors]

ANALYSIS:
[Why the conflict might exist]
[Which source is more reliable and why]
[Alternative explanations considered]

RESOLUTION:
[Your conclusion on which is correct]
[Reasoning supporting this conclusion]
[Any remaining uncertainty]
```

## Best Practices

### Do:
- Address every conflict, even minor ones
- Explain reasoning for each resolution
- Acknowledge when resolution isn't possible
- Document negative searches for resolving evidence
- Revisit if new evidence emerges

### Don't:
- Ignore inconvenient evidence
- Assume original records are always correct
- Dismiss family sources without analysis
- Pretend conflicts don't exist
- Stop researching when conflicts appear
