# Complete and Accurate Citations

GPS Element 2: Documenting sources so others can verify your work.

## The Standard

Every statement of fact must have a complete and accurate source citation that enables:
- **Relocation**: Others can find the source
- **Evaluation**: Others can assess its quality
- **Verification**: Others can check your interpretation

## What Makes a Citation Complete

### Essential Elements

| Element | Purpose | Example |
|---------|---------|---------|
| **Creator** | Who made it | Ohio Department of Health |
| **Title** | What it's called | Certificate of death |
| **Date** | When created/published | 1925 |
| **Location** | Where found | Muskingum County Probate Court |
| **Specific ID** | How to find exact item | Certificate no. 12345 |

### For Digital Sources, Add:

| Element | Purpose | Example |
|---------|---------|---------|
| **Platform** | Where accessed online | FamilySearch |
| **URL** | Web address | https://familysearch.org |
| **Access date** | When you saw it | 15 January 2024 |
| **Original cited** | What the digital is from | Citing Ohio Dept. of Health |

## Citation Accuracy

### Requirements

1. **Transcribe exactly**: Copy names, dates, places as written
2. **Note discrepancies**: If source conflicts with other evidence
3. **Identify errors**: Use [sic] for obvious errors in source
4. **Distinguish**: Separate what source says from what you conclude

### Common Accuracy Errors

| Error | Problem | Better |
|-------|---------|--------|
| Correcting names silently | Hides original | Record as written, note variant |
| Averaging dates | Creates false precision | Cite each source separately |
| Combining sources | Obscures origin | Cite each source independently |
| Omitting "cited as" | Unclear if verified | Note whether you saw original |

## Citation Completeness by Source Type

### Original Records

Must identify:
- Issuing authority
- Record type
- Subject name
- Date
- Unique identifier (certificate/page/entry number)
- Repository holding original

### Derivative Sources

Must identify:
- Creator of derivative (compiler, transcriber)
- Title of derivative work
- Publication information
- Specific page/entry
- Original source cited (if stated)

### Digital Images

Must identify:
- What the image shows (the original)
- Platform providing image
- Access information (URL, date)
- Citation to original if image is of another source

## Testing Your Citations

### The Stranger Test

> "Could a stranger find this exact source using only my citation?"

If no, add more detail.

### Verification Checklist

For each citation, verify:
- [ ] Someone else could locate this source
- [ ] Enough detail to find exact entry
- [ ] Repository or access point clear
- [ ] For online sources, platform and date included
- [ ] For derivatives, original source identified

## Building Citations During Research

### Capture at Discovery

Record citation information when you first encounter the source:
- Before analyzing content
- Before moving to next source
- Include all identifying information

### Information to Capture

```
Source Discovery Record

Date found: [date]
Repository: [where]
Call number/location: [shelf/file/folder]
Source type: [what kind of record]
Title/Description: [what it is]
Date of source: [when created]
Subjects: [names mentioned]
Specific location: [page/entry/item]
Digital access: [URL if applicable]
Notes: [condition, legibility, completeness]
```

### Organizing Citations

**By source**: Group all uses of one source
**By person**: Group all sources for one individual
**By research question**: Group all sources for one problem

## Citation Shortcuts (and their risks)

### Acceptable Shortcuts

**Subsequent references**: After full citation, use shortened form
```
Full: Ohio Department of Health, certificate of death no. 12345...
Short: Ohio death certificate no. 12345
```

**Standard abbreviations**: When commonly understood
```
NARA = National Archives and Records Administration
FHL = Family History Library
```

### Risky Shortcuts

| Shortcut | Risk |
|----------|------|
| "Ancestry" | Which database? Which record? |
| "Family records" | Whose family? What records? |
| "Census" | Which year? Where? |
| "See above" | If reorganized, reference breaks |

### Never Acceptable

- No citation at all
- "Internet" as source
- "Family tradition" without specifics
- Citations to other people's trees without verification

## Software Considerations

### Gramps Citation Model

Gramps separates:
- **Source**: The record/publication (one entry)
- **Citation**: Specific reference to source (multiple entries)

**Benefit**: Avoids duplicating source information
**Requirement**: Both source and citation must be complete

### Export Considerations

When exporting/sharing:
- Verify citations export completely
- Check that links between sources and citations work
- Test that others can understand citations

## Citation Maintenance

### Regular Review

Periodically check:
- URLs still work
- Repositories still hold records
- Abbreviations are defined
- Incomplete citations identified

### Updating Citations

When sources change:
- Note old and new access information
- Don't delete record that source existed
- Add note about change

## Quality Assurance

### Citation Audit

Review sample of citations against standards:
1. Select 10 random citations
2. Check each against criteria
3. Identify patterns in problems
4. Correct systematically

### Common Problems Found in Audits

| Problem | Fix |
|---------|-----|
| Missing access dates | Add for all online sources |
| Incomplete repository info | Add full location |
| Missing original citation | Add "citing..." when applicable |
| Vague page numbers | Clarify penned vs. stamped |
| No URL | Add for online sources |
