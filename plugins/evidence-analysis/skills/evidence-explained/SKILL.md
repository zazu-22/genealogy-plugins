# Evidence Explained Citation Methodology

Expert knowledge for citing genealogical sources using Elizabeth Shown Mills' Evidence Explained system.

## When This Skill Applies

- Creating source citations for genealogical research
- Formatting references for different source types
- Documenting digital and online sources
- Converting between citation formats
- Understanding citation components

## Core Principles

### Why Citations Matter

1. **Relocate the source** - Find it again or enable others to find it
2. **Evaluate the source** - Understand its nature and limitations
3. **Credit the creator** - Acknowledge original work
4. **Enable verification** - Allow others to check your work

### The Golden Rule

> "If you can't cite it, you can't use it as evidence."

## Citation Types

| Type | Purpose | Use |
|------|---------|-----|
| **Source List** | Bibliography entry | Publications, reports |
| **First Reference Note** | Full citation, first use | Footnotes/endnotes |
| **Subsequent Note** | Shortened citation | Repeat references |
| **Source Label** | Standalone identification | Photocopies, attachments |

## Quick Format Guide

### Basic Elements (in order)

1. **Creator** - Who made it (author, agency, compiler)
2. **Title** - What is it called
3. **Publication facts** - Where/when published (in parentheses)
4. **Location** - Where found (repository, URL)
5. **Specific location** - Page, entry, item number

### Punctuation Rules

- Elements separated by **commas**
- Use **semicolons** when elements contain commas
- Publication data in **(parentheses)**
- Titles in **"quotes"** or *italics* as appropriate

## Common Source Patterns

### Census Records
```
[Year] U.S. Census, [State], [County], [Township/City],
page [X], [dwelling/family], [Name]; digital image,
[Website] (URL : accessed [date]), citing NARA microfilm [roll].
```

### Vital Records
```
[Jurisdiction], [Record Type], [Name] [event], [date],
[certificate/entry number]; [Repository], [Location].
```

### Digital Databases
```
[Database name], database with images, [Website]
(URL : accessed [date]), entry for [Name], [event], [date].
```
