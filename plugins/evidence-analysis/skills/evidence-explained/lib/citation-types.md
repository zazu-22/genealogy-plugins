# Citation Types

Understanding the four citation formats in Evidence Explained.

## Overview

Evidence Explained defines four distinct citation formats, each serving a specific purpose:

| Type | Format | Primary Use |
|------|--------|-------------|
| Source List | Bibliography style | Published works, reports |
| First Reference Note | Full note style | First mention in notes |
| Subsequent Note | Abbreviated | Repeat references |
| Source Label | Standalone | Photocopies, files |

## Source List (Bibliography) Entry

### Purpose
- Bibliographies in published works
- Source lists in reports
- Organized reference collections

### Characteristics
- Arranged alphabetically by first element
- No page numbers (those go in notes)
- Lead element determines sort position

### Format
```
Lead Element. Title. Publication Data. Location Data.
```

### Examples

**Book**:
```
Mills, Elizabeth Shown. Evidence Explained: Citing History Sources
    from Artifacts to Cyberspace. 4th ed. Baltimore: Genealogical
    Publishing Co., 2024.
```

**Census**:
```
1850 U.S. Census, Muskingum County, Ohio. Digital images.
    Ancestry.com. https://www.ancestry.com : accessed 2024.
```

**Vital Record Collection**:
```
Ohio. Deaths, 1908–1953. Digital images. FamilySearch.
    https://www.familysearch.org : 2024.
```

### Lead Element Determination

| Source Type | Lead Element |
|-------------|--------------|
| Authored work | Author surname |
| Government record | Jurisdiction |
| Organizational record | Organization |
| Collection/Database | Collection title |
| Church records | Church name |

## First Reference Note

### Purpose
- Footnotes and endnotes
- First time citing a source
- Complete identification for later reference

### Characteristics
- Sentence-style formatting (commas between elements)
- Publication data in parentheses
- Includes specific location (page, entry)
- Designed to be read as prose

### Format
```
Creator, "Title," Publication Data (Location: Publisher, Date),
specific location; access information.
```

### Examples

**Book**:
```
¹Elizabeth Shown Mills, Evidence Explained: Citing History Sources
from Artifacts to Cyberspace, 4th ed. (Baltimore: Genealogical
Publishing Co., 2024), 47.
```

**Census**:
```
²1850 U.S. Census, Muskingum County, Ohio, population schedule,
Zanesville, p. 123 (penned), dwelling 45, family 47, John Smith;
digital image, Ancestry.com (https://www.ancestry.com : accessed
15 January 2024), citing NARA microfilm publication M432, roll 723.
```

**Vital Record**:
```
³Ohio Department of Health, certificate of death no. 12345 (1925),
Mary Jones; digital image, "Ohio, Deaths, 1908–1953," FamilySearch
(https://www.familysearch.org : accessed 15 January 2024).
```

### Note Numbers
- Sequential through document
- Or restart each chapter
- Superscript or inline with period

## Subsequent Note

### Purpose
- Repeat references in notes
- When source already fully cited
- Reduce repetition

### Characteristics
- Abbreviated form
- Includes enough to identify
- References back to full citation

### Format
```
Short title or identifier, specific new location.
```

### Examples

**Book (after full citation)**:
```
⁴Mills, Evidence Explained, 52.
```

**Census (after full citation)**:
```
⁵1850 U.S. Census, Muskingum Co., Ohio, p. 125, dwell. 48, fam. 50,
James Wilson.
```

**Vital Record (after full citation)**:
```
⁶Ohio death certificate no. 12346 (1927), Thomas Brown.
```

### Traditional Short Forms

| Form | Use | Example |
|------|-----|---------|
| Ibid. | Same source, same page | Ibid. |
| Ibid., [page] | Same source, different page | Ibid., 53. |
| [Author], [short title] | Previously cited | Mills, Evidence Explained |

**Note**: *Ibid.* increasingly avoided in modern practice; some prefer always using short title form.

## Source Label

### Purpose
- Identify copies, abstracts, and transcriptions
- Label research files
- Standalone documentation

### Characteristics
- Complete in itself
- No reference to other notes
- May use either note or bibliography format

### Use Cases
- Photocopy of document
- Research file cover sheet
- Citation attached to image
- Database entry

### Format Options

**Note format**:
```
[Full first-reference note format]
```

**Label format** (condensed):
```
Source: [Title/identification]
Created: [Date of original]
Found: [Repository]
Copied: [Date obtained]
```

### Examples

**Photocopy label**:
```
Ohio Department of Health, certificate of death no. 12345 (1925),
Mary Jones; "Ohio, Deaths, 1908–1953," digital image, FamilySearch
(https://www.familysearch.org : accessed 15 January 2024).
Downloaded 15 January 2024.
```

**File folder label**:
```
SMITH, John (1805–1880)
Census Records
- 1850 Muskingum Co., Ohio
- 1860 Muskingum Co., Ohio
- 1870 Muskingum Co., Ohio
Source: Ancestry.com digital images; accessed January 2024
```

## Choosing the Right Type

### Decision Guide

| Situation | Use |
|-----------|-----|
| Writing a report with footnotes | First Reference → Subsequent |
| Creating a bibliography | Source List |
| Labeling a photocopy | Source Label |
| Research database entry | Source Label or First Reference |
| Genealogy software | First Reference (modified) |
| Quick working notes | Subsequent Note format |

### Software Considerations

**Gramps and similar software**:

- Source record: Like bibliography entry
- Citation record: Like first reference note (page/detail)

**Genealogy reports**:

- First mention: Full citation
- Repeated: Abbreviated
