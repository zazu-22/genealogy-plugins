# Digital Sources

Citing websites, databases, online repositories, and DNA test results.

## Principles for Digital Citations

### Key Requirements

1. **Identify the original** - What is the underlying source?
2. **Document the digital path** - How did you access it?
3. **Record access date** - Websites change
4. **Provide enough detail to relocate** - URLs, database names, search paths

### Digital Source Types

| Type | Example |
|------|---------|
| Image of original | Scan of original document |
| Database | Searchable index or transcription |
| Database with images | Index linked to document images |
| Derivative database | Compiled from multiple sources |
| Born-digital | Content created digitally |

## Major Genealogy Platforms

### FamilySearch

**Database with images**:
```
"[Database name]," database with images, FamilySearch
(https://www.familysearch.org : accessed [date]), entry for
[Name], [event], [date and place].
```

**Example**:
```
"Ohio, Deaths, 1908–1953," database with images, FamilySearch
(https://www.familysearch.org : accessed 15 January 2024), entry
for John Smith, death, 15 March 1925, Zanesville, Muskingum County.
```

**Database only (no images)**:
```
"[Database name]," database, FamilySearch
(https://www.familysearch.org : accessed [date]), entry for
[Name], [details].
```

**Film/Fiche digitized**:
```
[Original citation]; digital images, "[Collection name],"
FamilySearch (https://www.familysearch.org : accessed [date]),
film [number], image [X].
```

### Ancestry.com

**Database with images**:
```
[Database name], database with images, Ancestry.com
(https://www.ancestry.com : accessed [date]), entry for [Name];
citing [original source].
```

**Example**:
```
1850 U.S. Federal Census, database with images, Ancestry.com
(https://www.ancestry.com : accessed 15 January 2024), entry for
John Smith, Zanesville, Muskingum County, Ohio; citing NARA
microfilm M432, roll 723.
```

**Family tree citation** (use with caution):
```
[Tree name], Ancestry.com (https://www.ancestry.com : accessed
[date]), profile for [Person], created by [username]; privately
held, unverified.
```

### FindMyPast

```
[Database name], database with images, FindMyPast
(https://www.findmypast.com : accessed [date]), entry for [Name];
citing [original source if known].
```

### MyHeritage

```
[Database name], database, MyHeritage (https://www.myheritage.com :
accessed [date]), entry for [Name].
```

## Government and Archive Websites

### National Archives (NARA)

**Digital image via NARA**:
```
[Description of record], [date]; [Record Group], [Series],
[File Unit]; digital image, National Archives Catalog
(https://catalog.archives.gov : accessed [date]).
```

### State Archives

```
[Record type], [details]; [State Archives name], [city]; digital
image, [website if applicable] (URL : accessed [date]).
```

### FamilySearch Catalog vs. Collections

**Catalog (metadata only)**:
```
FamilySearch catalog (https://www.familysearch.org/search/catalog :
accessed [date]), [record description], [film/digital note].
```

**Collection (with images)**:
```
"[Collection name]," images, FamilySearch (https://www.familysearch.org :
accessed [date]), [path to specific image].
```

## Cemetery and Memorial Sites

### Find A Grave

```
Find A Grave, database and images (https://www.findagrave.com :
accessed [date]), memorial [number] for [Name] ([birth year]–
[death year]), [Cemetery name], [City], [County], [State].
```

**Example**:
```
Find A Grave, database and images (https://www.findagrave.com :
accessed 15 January 2024), memorial 12345678 for John Smith
(1850–1925), Woodlawn Cemetery, Zanesville, Muskingum County, Ohio.
```

### BillionGraves

```
BillionGraves, database and images (https://billiongraves.com :
accessed [date]), entry for [Name], [Cemetery], [Location].
```

## DNA Test Results

### General Format

```
[Testing company], [test type] results for [Tester name], [kit
number or identifier]; [access method] (URL : accessed [date]).
```

### Company-Specific

**AncestryDNA**:
```
AncestryDNA, autosomal DNA test results for [Name]; Ancestry.com
(https://www.ancestry.com/dna : accessed [date]), [username]
account, kit [number if known].
```

**23andMe**:
```
23andMe, autosomal DNA test results for [Name]; 23andMe.com
(https://www.23andme.com : accessed [date]), [account identifier].
```

**FamilyTreeDNA**:
```
FamilyTreeDNA, [test type: atDNA/Y-DNA/mtDNA] results for [Name],
kit [number]; FTDNA (https://www.familytreedna.com : accessed [date]).
```

### DNA Match Citations

```
[Testing company], DNA match between [Tester 1] and [Tester 2],
[relationship estimate], [shared cM]; [access method] (accessed [date]).
```

### Third-Party Analysis Tools

**GEDmatch**:
```
GEDmatch, [analysis type] for kit [number]; GEDmatch.com
(https://www.gedmatch.com : accessed [date]).
```

**DNA Painter**:
```
DNA Painter, chromosome map for [Name]; DNAPainter.com
(https://dnapainter.com : accessed [date]).
```

## Social Media and User-Generated Content

### General Caution
User-generated content is **rarely reliable** as primary evidence. Cite as leads only. However, social media posts can serve as:
- Informant statements (the poster reporting what they know)
- Leads to pursue with original sources
- Documentation of family oral tradition

### Facebook

**Personal Page Post**:
```
[Name], posting on personal page, Facebook ([URL] : [date and time
of post]), [description of content].
```

**Example**:
```
Chelsea Smith Humphries, posting on personal page, Facebook
(https://www.facebook.com/chelsea.humphries : 21 June 2014),
announcing birth of grandson [Name].
```

**Group Page Post**:
```
[Name], posting at "[Group Name]," Facebook ([URL] : [date]),
[description of content].
```

**Comment on Another's Post**:
```
[Original Poster], posting at "[Group/Page]," Facebook ([URL] :
[date]), comment by [Commenter Name], [comment date].
```

**For Gramps**:
- **Source title**: `[Poster Name], Personal Page, Facebook`
- **Citation page**: `Post dated [date], [brief description]`
- **Repository**: Private Collection (the researcher saved/observed it)

**Note**: Facebook URLs can become inaccessible. Save screenshots or note key details in citation.

### Message Boards and Forums

```
[Thread title], [Board/Forum name] (URL : accessed [date]),
post by [username], [date of post].
```

### Personal Websites

```
[Author if known], "[Page title]," [Website name] (URL : accessed
[date]).
```

## Access Information

### Recording Access Dates

**Always include** for:
- Database searches
- Website consultations
- Online images

**Evidence Explained Format**:
```
(https://www.example.com : accessed 15 January 2024)
```

### Digital Access in Gramps

**IMPORTANT: Use Notes, Not Attributes** for digital access information.

Per Gramps community best practices:
- Source/Citation Attributes have **no GEDCOM equivalent** and won't export
- Notes are searchable via Gramps filters
- URLs change; notes allow context (e.g., "previously at...")

**Gramps Note Format**:
```
Digital access: [Website] ([URL] : accessed [Date])
```

**Examples**:
```
Digital access: Newspapers.com (http://www.newspapers.com/image/19309759/ : accessed 23 Jun 2014)

Digital access: FamilySearch (https://www.familysearch.org/ark:/61903/1:1:ABCD-1234 : accessed 15 Jan 2024)

Digital access: Ancestry.com (https://www.ancestry.com/discoveryui-content/view/12345:1234 : accessed 10 Mar 2024)
```

**Attach Note To**:
- Citation: When the access info is specific to that citation
- Source: When the entire source is digital and one access point serves all citations

See `docs/gedcom-gramps-field-mapping.md` for complete GEDCOM-Gramps field mapping guidance

### URL Best Practices

**Use persistent/permanent links when available**:
- FamilySearch: ARK links
- NARA: Catalog permanent links
- Academic journals: DOI links

**For dynamic URLs**:
- Record the path taken to reach the record
- Note search terms used
- Include database/collection name

### When URLs Change

If returning to a source and URL changed:
- Update citation with new URL
- Note "previously at [old URL]" if significant
- Record new access date

## Born-Digital Sources

### Email

```
[Author], email to [Recipient], [date], "[Subject line]";
privately held by [holder], [location].
```

### Electronic Documents

```
[Author], "[Document title]," [format] file, [date created];
[access information or holder].
```

### Online Publications

```
[Author], "[Title]," [Publication name] (URL : published [date]),
accessed [date].
```

## Quality Assessment for Digital Sources

### Questions to Ask

1. **What is the original source?**
   - Is this an image of an original or a transcription?
   - Who created the original?

2. **How was it digitized?**
   - By a reliable institution?
   - With quality controls?

3. **Is it complete?**
   - Are pages/entries missing?
   - Is it a selection or comprehensive?

4. **How current is it?**
   - When was it last updated?
   - Have corrections been made?

### Red Flags

- No identification of original source
- User-submitted without verification
- Missing access dates in your notes
- Broken links without alternative documentation
