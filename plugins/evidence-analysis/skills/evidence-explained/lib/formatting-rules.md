# Formatting Rules

Style conventions for Evidence Explained citations.

## Punctuation

### Between Elements

**Comma (,)**: Separates most elements in reference notes
```
John Smith, "Article Title," Journal Name 15 (2024): 45.
```

**Semicolon (;)**: Separates elements when internal commas exist
```
Zanesville, Ohio; digital image, Ancestry.com.
```

**Colon (:)**: Before page numbers, volume:page, after access URL
```
Journal Name 15 (2024): 45.
Book 12:345.
(https://www.example.com : accessed 15 January 2024)
```

**Period (.)**: Ends citation; separates elements in bibliography
```
Smith, John. Title. Place: Publisher, 2024.
```

### Special Cases

**Parentheses**:

- Publication data: (Baltimore: Publisher, 2024)
- Access information: (https://www.example.com : accessed [date])
- Clarifications: (penned), (stamped)

**Brackets**:

- Editorial additions: [sic], [illegible], [1850?]
- Missing information supplied: [Ohio]
- Uncertain readings: [Mary?]

**Quotation marks**:

- Article and chapter titles
- Unpublished documents
- Database names within larger platforms

## Titles and Names

### Italics vs. Quotation Marks

| Use Italics | Use Quotation Marks |
|-------------|---------------------|
| Books | Articles |
| Journals/Periodicals | Chapter titles |
| Newspapers | Database names |
| Major collections | Manuscript titles |
| Website names | Individual document names |

### Examples
```
Evidence Explained (book - italic)
"Ohio, Deaths, 1908–1953" (database name - quotes)
Ancestry.com (website - italic)
"John Smith" (article title - quotes)
```

### Creator Names

**Single author**:

- Note: John Smith, Title...
- Bibliography: Smith, John. Title...

**Multiple authors**:

- Note: John Smith and Jane Doe, Title...
- Bibliography: Smith, John, and Jane Doe. Title...

**Corporate author**:

- Ohio Department of Health, certificate...
- National Archives, pension file...

**No author**:

- Lead with title
- "Article Title," Source...

### Personal Names in Content

**Preserve original spelling**:

- John SMITH (if caps in original)
- Mary Jones or JONES (as recorded)

**Standardize for indexing**:

- SURNAME, Given names
- Cross-reference variants

## Dates

### Format

**Preferred**: Day Month Year
```
15 March 1925
12 January 2024
```

**In parentheses** (publication): Month Year or just Year
```
(January 2024)
(2024)
```

**Access dates**: Day Month Year
```
accessed 15 January 2024
```

### Uncertain Dates

| Situation | Format | Example |
|-----------|--------|---------|
| Approximate | ca. [year] | ca. 1850 |
| Before | bef. [date] | bef. March 1850 |
| After | aft. [date] | aft. 15 March 1850 |
| Between | [date]–[date] | 1850–1855 |
| Uncertain | [date?] | 1850? |

### Date Ranges

**Spans**: Use en-dash (–) not hyphen (-)
```
1850–1855
January–March 1850
```

**Life dates**: (birth–death)
```
John Smith (1850–1925)
```

## Numbers

### Page Numbers

**Single page**: p. 45 or page 45
**Multiple pages**: pp. 45–47 or pages 45–47
**Unnumbered**: [p. 3] or unpaged

**Census pages**:

- Penned vs. stamped: p. 123 (penned)
- Both numbers: p. 123A (penned), stamped 246

### Volume and Issue

**Colon format**: Volume:page
```
Book 12:345
```

**Parenthetical format**: Volume (Issue): page
```
Journal 15 (2): 45
```

### Numbered Records

**Certificates**: no. 12345 or certificate no. 12345
**Files**: file no. 456
**Cases**: case no. 789

## Capitalization

### Title Case
Use for:

- Book titles
- Article titles
- Database names
- Repository names

**Rules**:

- Capitalize major words
- Lowercase articles (a, an, the) unless first word
- Lowercase prepositions unless first word
- Lowercase conjunctions unless first word

### Sentence Case
Use for:

- Descriptive elements in notes
- Running text

### Preserve Original Capitalization
When:

- Quoting directly from source
- Recording names as written
- Reproducing titles exactly

## Abbreviations

### Standard Abbreviations

| Term | Abbreviation |
|------|-------------|
| page | p. |
| pages | pp. |
| volume | vol. |
| number | no. |
| circa | ca. |
| county | Co. |
| edition | ed. |
| editor | ed. |
| compiler | comp. |
| translator | trans. |
| manuscript | MS |
| folio | fol. |

### State Abbreviations

**Preferred**: Full name or standard postal abbreviation
```
Ohio or OH
Pennsylvania or PA
```

**Avoid**: Old-style abbreviations (O., Penn.)

### Repository Abbreviations

**First reference**: Spell out completely
```
National Archives and Records Administration
```

**Subsequent**: May abbreviate after defining
```
NARA
```

## Electronic Formatting

### URLs

**Format**: In parentheses with space-colon-space before "accessed"
```
(https://www.ancestry.com : accessed 15 January 2024)
```

**Long URLs**: May break after slashes
**Persistent links**: Prefer when available

### Database Names

**Within platforms**:
```
"Ohio, Deaths, 1908–1953," database with images, FamilySearch
```

**Standalone databases**:
```
Find A Grave, database and images
```
