# Source Categories

Citation patterns for common genealogical source types.

## Census Records

### U.S. Federal Census

**First Reference Note**:
```
[Year] U.S. census, [State], [County], [Township/City/District],
population schedule, [page] ([penned/stamped]), dwelling [X],
family [Y], [Name of head]; digital image, [Website]
([URL] : accessed [date]), citing NARA microfilm [publication, roll].
```

**Example**:
```
1850 U.S. census, Ohio, Muskingum County, Zanesville, population
schedule, p. 123 (penned), dwelling 45, family 47, John Smith;
digital image, Ancestry.com (https://www.ancestry.com : accessed
15 January 2024), citing NARA microfilm M432, roll 723.
```

### State and Local Census

```
[Year] [State] census, [County], [Township/City], [page/line],
[Name]; [Repository or digital source], [access information].
```

### Non-Population Schedules

```
[Year] U.S. census, [State], [County], [schedule type] schedule,
[page], [entry for Name or property]; [source information].
```

**Schedule types**: Agricultural, Manufacturing, Mortality, Social Statistics, Slave

## Vital Records

### Birth Certificates

```
[Jurisdiction], [record type], [name], [date of birth],
certificate/file no. [X]; [Repository or digital source].
```

**Example**:
```
Ohio Department of Health, certificate of birth no. 12345,
Mary Jane Smith, 15 March 1920; digital image, "Ohio, Births,
1908–1954," FamilySearch (https://www.familysearch.org :
accessed 15 January 2024).
```

### Death Certificates

```
[Jurisdiction], certificate of death no. [X] ([year]), [Name];
[Repository or digital source].
```

**Example**:
```
Muskingum County, Ohio, death certificate no. 456 (1950),
John William Smith; County Probate Court, Zanesville.
```

### Marriage Records

**License/Certificate**:
```
[Jurisdiction], marriage license/certificate, [Groom] and [Bride],
[date], [file/book/page]; [Repository or digital source].
```

**Published Index**:
```
[Compiler], [Title] (Publication info), [page], [names].
```

## Church Records

### Baptism/Christening

```
[Church Name], [Location], [record type], [date], [child's name],
child of [parents]; [Repository or digital source].
```

**Example**:
```
First Presbyterian Church, Zanesville, Ohio, baptismal register,
15 April 1875, Mary Elizabeth, daughter of John and Sarah Smith;
church records, on file at church office.
```

### Marriage

```
[Church Name], [Location], marriage register, [date], [groom]
and [bride]; [Repository or digital source].
```

### Burial

```
[Church Name], [Location], burial register, [date], [name],
[age/details]; [Repository or digital source].
```

## Land and Property Records

### Deeds

```
[County], [State], Recorder of Deeds, deed book [X]:[page],
[Grantor] to [Grantee], [date recorded]; [Repository].
```

**Example**:
```
Muskingum County, Ohio, Recorder of Deeds, deed book 45:123,
John Smith to William Jones, recorded 15 March 1875; County
Recorder's Office, Zanesville.
```

### Land Patents/Grants

```
[Jurisdiction], [land office], [patent type], [Name], [date],
[legal description]; [Repository or digital source].
```

### Tax Records

```
[County], [State], tax list [year], [Name], [property description];
[Repository or digital source].
```

## Probate Records

### Wills

```
[County], [State], Probate Court, will of [Name], [date executed],
[date probated], will book [X]:[page]; [Repository].
```

**Example**:
```
Muskingum County, Ohio, Probate Court, will of John Smith,
executed 15 March 1870, probated 10 June 1875, will book 12:45;
Probate Court, Zanesville.
```

### Estate Inventories/Administrations

```
[County], [State], Probate Court, estate of [Name], [record type],
[date], [case/file no.]; [Repository].
```

### Guardianships

```
[County], [State], Probate Court, guardianship of [Minor Name],
[Guardian Name], guardian, [date appointed], [case no.];
[Repository].
```

## Military Records

### Service Records

```
[Name], [service record type], [war/era], [unit]; National Archives,
Washington, D.C., [record group], [series/file].
```

### Pension Records

```
[Name], pension application no. [X], [war]; National Archives,
Washington, D.C., [record group]; [digital source if applicable].
```

### Draft Registrations

```
[Name], [draft registration], [date], [location]; [Repository
or digital source].
```

## Newspaper Sources

### Obituaries

```
"[Headline if any]," [Newspaper Name] ([City, State]), [date],
[page], [column]; [digital source or repository].
```

**Example**:
```
"John Smith, Pioneer Resident, Dies," Zanesville Times Recorder
(Zanesville, Ohio), 15 March 1925, p. 3, col. 2; digital image,
Newspapers.com (https://www.newspapers.com : accessed 15 January 2024).
```

### News Articles

```
"[Headline]," [Newspaper Name] ([City, State]), [date], [page],
[column]; [Repository or digital source].
```

### Announcements (Birth, Marriage, etc.)

```
[Newspaper Name] ([City, State]), [date], [page], [column],
[description of announcement]; [Repository or digital source].
```

## Cemetery Records

### Gravestone Inscriptions

```
[Cemetery Name], [City], [County], [State], [section/lot/row],
gravestone of [Name], [inscription or dates noted]; [personal
observation, date] or [transcription source].
```

**Example**:
```
Woodlawn Cemetery, Zanesville, Muskingum County, Ohio, Section B,
Lot 45, gravestone of John Smith, "Born Mar. 15, 1850, Died
June 10, 1925"; personally read by [Your Name], 15 August 2024.
```

**For Gramps**:
- **Source title**: `[Cemetery Name], [City], [County], [State]`
  - Example: `Greenwood Cemetery, Zanesville, Muskingum County, Ohio`
- **Citation page**: `Section [X], Lot [Y], gravestone of [Name], [inscription]`
- **Repository**: Private collection (for personal observations)

**Rationale**: Using cemetery as the source (not the individual headstone) allows the source to be reused for multiple gravestones in the same cemetery. The person-specific details go in the citation.

### Sexton's Records

```
[Cemetery Name], sexton's records, [Name], burial [date],
[lot/section]; [Repository].
```

## City Directories

### Published Directories

```
[City, State, City Directory, Year] ([Publisher, Location, Year]),
[page], [entry for Name]; [Repository or digital source].
```

**Example**:
```
Zanesville, Ohio, City Directory, 1928 (R.L. Polk & Co., 1928),
p. 234, entry for John Smith, printer; digital image, "U.S. City
Directories, 1821-1989," Ancestry.com (https://www.ancestry.com :
accessed 15 January 2024).
```

### Consolidation Guidance

Unlike census records (which consolidate by year because they're all from the same federal entity), city directories should be kept **separate** per city and year because:

- Each directory is a distinct publication
- Different publishers compiled each one
- Different cities, different editorial standards
- The directory itself is the source, not a database

**For Gramps**:
- **Source title**: `[City], [State], City Directory, [Year]`
- **Citation page**: `p. [X], entry for [Name], [occupation]`
- **Repository**: Ancestry (when accessed via U.S. City Directories database)

## Compiled Sources

### Published Genealogies

```
[Author], [Title] (Publication info), [page], [specific person
or family discussed].
```

### County/Local Histories

```
[Author/Compiler], [Title] ([Publisher, Location, Year]), [page],
[subject or family]; [Repository or access method].
```

**Example**:
```
N.N. Hill, Jr., History of Coshocton County, Ohio (A.A. Graham & Co.,
Newark, Ohio, 1881), p. 567, Richardson family.
```

**Note**: These are authored works—verify claims against original sources.

### Lineage Society Applications

```
[Society Name], application papers, [applicant name], [application
number], [date]; [Repository or digital access].
```

## Mapping Evidence Explained to Gramps

### The Source-Citation Model

Evidence Explained's layered citation approach maps directly to Gramps:

| EE Element | Gramps Field | Example |
|------------|--------------|---------|
| Source/publication title | Source `stitle` | 1900 United States Federal Census |
| Author/creator | Source `sauthor` | U.S. Census Bureau |
| Publication info | Source `spubinfo` | Washington, D.C.: NARA |
| Specific reference | Citation `page` | Ohio, Muskingum, ED 73, Sheet 11A |
| Repository | Source `reporef` | National Archives |
| Access date | Citation attribute | 15 January 2024 |
| Confidence | Citation `confidence` | 3 (High) |

### Consolidation Decision Framework

When deciding whether to consolidate sources or keep them separate:

**Consolidate when**:
- Same creating entity (e.g., all census years from U.S. Census Bureau)
- Same database/collection concept (e.g., all Find A Grave entries)
- Same index/database (e.g., SSDI via Ancestry)
- Differences are captured in citation details

**Keep separate when**:
- Different publishers/creators (e.g., city directories)
- Each is a distinct publication (e.g., books, newspapers)
- Physical documents you possess (e.g., certificates, interviews)
- The item itself is unique (e.g., wills, obituaries)

### Source Title Patterns

| Source Type | Title Pattern | Consolidate? |
|-------------|--------------|--------------|
| Federal Census | `[Year] United States Federal Census` | Yes, by year |
| State Census | `[State] State Census, [Year Range]` | Yes |
| Death Index/DB | `[State] Deaths, [Year Range]` | Yes |
| City Directory | `[City], [State], City Directory, [Year]` | No |
| Newspaper Article | `[Headline or Description]` | No |
| Headstone | `[Cemetery], [City], [County], [State]` | Cemetery-level |
| Interview | `Interview with [Person]` | No |
| Find A Grave | `Find A Grave` | Yes (one source) |
| SSDI | `U.S. Social Security Death Index, [Year Range]` | Yes (one source) |
